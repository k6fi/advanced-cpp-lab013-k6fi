# Lab 13 — Sorting Algorithms: Merge Sort and Quick Sort

## Course
CS 20 — Advanced Programming with C++

## Objective
This lab explores two foundational sorting algorithms: merge sort and quick sort. Students must implement both and provide a rigorous analysis of their correctness, complexity, and trade-offs.

## Required tasks
Students must implement:

- merge sort on a vector of integers;
- quick sort on a vector of integers;
- a helper to validate sorted order;
- recursive merge and partition logic;
- an explanation of best-, average-, and worst-case complexity.

## Deliverables
Students should submit:

- a working implementation of both algorithms;
- unit tests covering edge cases and repeated values;
- a short technical write-up comparing merge sort and quick sort;
- clear code comments explaining the algorithmic strategy.

## Important note
The starter project intentionally leaves the core sorting logic unimplemented so that students must complete the actual algorithmic work and verify correctness with tests.
